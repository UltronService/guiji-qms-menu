# 龜記叫號取餐系統與電子菜單看板 (Guiji QMS and Menu Board)

這是一個專為 Android 機上盒 (WebView) 設計的 9:16 直立式滿版 (1080x1920) 叫號取餐系統與電子菜單看板。主打 **100% 離線運作、零外部依賴、極速載入**。

## 🌟 核心功能

* **自適應滿版縮放**：採用原生 CSS `transform: scale` 與 JavaScript 計算，自動等比縮放以適應不同的螢幕與預覽視窗，無捲軸干擾。
* **USB 掃碼槍支援 (HID 模式)**：全域監聽鍵盤連發事件，並具備 Buffer 緩衝邏輯以精準捕捉掃碼槍的高速輸入 (可過濾 <100ms 間隔字元)，支援包含英數字首的單號 (例如 `A01`, `NO.88`)。
* **狀態保存 (LocalStorage)**：斷電或重新整理時，自動從 localStorage 復原最新的主號碼與歷史號碼。
* **聲光回饋 (完全離線)**：
  * **音效**：使用 `Web Audio API` 雙正弦波合成清脆的雙音「Ding-Dong」，不依賴任何外部 MP3/WAV 檔案。
  * **語音廣播**：調用原生 `Web Speech API` 進行 TTS 語音合成朗讀 (「請 XXX 取餐」)。
* **測試與除錯面板**：按下 `T` 鍵即可呼叫內建的動態調校面板，提供手動輸入、測試數據、一鍵清空、自動輪播 Demo 模式、字體選擇、綠底透明度滑桿，以及**歷史號碼排版方向切換 (橫向/直向)**。

## 🎨 UI / UX 設計

* **整體版面配置**：
  * 上方 15%：即時叫號橫幅 (QMS)，採用動態品牌影片作為橫幅背景。
  * 下方 85%：靜態菜單圖片展示區 (`assets/menu.jpg`)。
* **叫號動態效果與待機模式**：
  * **待機模式 (Standby Mode)**：無號碼時，Logo 置中放大展示，營造質感品牌形象。
  * **轉場動畫**：第一筆訂單掃入時，Logo 平滑移至左側，主號碼緊接彈出。
  * 最新號碼具備進場彈跳 (Pop-in) 動畫，且超過 4 碼時自動微調字級大小。
  * 佇列邏輯採用 **1 主號碼 + 2 歷史號碼** (`MAX_HISTORY = 2`) 輪替顯示。
  * **多樣化歷史號碼排版模式**（可於面板隨時切換，設定自動保存）：
    * **橫向排版（預設）**：由左至右排列，左邊 Index 0（最新退役號碼），右邊 Index 1（較舊號碼），採 GPU 平順向右推移滑動。
    * **直向排版**：由下至上排列，下面 Index 0（最新退役號碼），上面 Index 1（較舊號碼）；新號碼由下方平順向上滑入並淡入，歷史號碼由下往上平順推移。
  * 若重複掃描目前的號碼，會自動將其置頂並重新觸發聲光回饋。

## 🛠 技術堆疊

* **純原生 Vanilla JavaScript (ES6)**
* **HTML5 + CSS3**
* 完全無 CDN、無框架 (Zero Dependencies)，保證機上盒環境中最流暢的運行效率。

## 🚀 部署與執行

1. Clone 本專案。
2. 確保專案根目錄下的 `assets/` 資料夾內有 `menu.jpg` 菜單圖片與 `logo2.svg` 品牌商標。
3. 直接以瀏覽器開啟 `index.html` 即可運行。
